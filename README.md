# Grafana Provisioning File Example

This example demonstrates a Grafana provisioning file in YAML format. It shows how to automatically configure data sources like Prometheus and InfluxDB, and outlines how dashboards and alert rules can be provisioned. This enables a 'Grafana as Code' approach for consistent and repeatable Grafana deployments.

## Language

`yaml`

## How to Run

1. Save this content as `grafana-provisioning.yaml`.
2. Place it in Grafana's provisioning directory (e.g., `/etc/grafana/provisioning/datasources/`).
3. Restart Grafana for the changes to take effect.
